# Content Audit Generator

## What This Does
Takes prospect research and generates a professional content audit report. This is your #1 sales tool. The audit should be SO good that the prospect thinks "if the free stuff is this quality, the paid work must be incredible."

## How to Use

1. Research the prospect (10 minutes):
   - Copy text from their homepage + 2 product pages + about page
   - Sign up for their email list, note what happens
   - Check Instagram/TikTok, note quality and frequency
   - Check Meta Ad Library for active ads
   - Identify 1-2 competitors

2. Fill in the variables below and paste the whole prompt into Claude

3. Review the output — make sure specific examples are accurate (Claude may hallucinate their content if you didn't paste enough)

4. Export as PDF with CopyDTC branding

5. Send using email template #1 from operations/email-templates.md

Time from research to delivered audit: 30-45 minutes.

## The Prompt

Paste everything below this line into Claude:

---

You are the lead content strategist at CopyDTC, an AI-powered copywriting agency for DTC brands. Create a content audit for a prospective client. Be insightful, specific, and honest. Acknowledge what they do well. Be direct about what needs work. Every recommendation must be specific to their brand, not generic advice.

**Prospect info:**
- Company: [COMPANY_NAME]
- Website: [WEBSITE_URL]
- Category: [INDUSTRY/PRODUCT_CATEGORY]
- Price range: [PRICE_RANGE]
- Competitor 1: [COMPETITOR_1]
- Competitor 2: [COMPETITOR_2]

**Their website copy (paste below):**
[PASTE HOMEPAGE, 2 PRODUCT PAGES, ABOUT PAGE TEXT]

**Their email signup experience:**
[WHAT HAPPENED WHEN YOU SIGNED UP — welcome email? discount? nothing?]

**Their social media:**
[INSTAGRAM/TIKTOK NOTES — posting frequency, caption quality, engagement]

**Their ads:**
[META AD LIBRARY FINDINGS — running ads? how many? what do they look like?]

---

Generate this report:

### CONTENT AUDIT: [COMPANY_NAME]

**Prepared by:** CopyDTC | copydtc.com
**Date:** [TODAY'S DATE]
**Confidential** — prepared exclusively for [COMPANY_NAME]

---

**EXECUTIVE SUMMARY**
Write 3-4 sentences. High-level assessment of their content health. Include one specific data point. Frame as: "Here's where you are and here's the opportunity."

**CONTENT SCORECARD**
Grade each area A through F with a one-sentence explanation:

| Area | Grade | Assessment |
|------|-------|------------|
| Homepage & Website Copy | | |
| Email Marketing | | |
| Product Descriptions | | |
| Social Media | | |
| Paid Advertising | | |
| Brand Voice Consistency | | |
| Conversion Elements | | |
| SEO & Content Strategy | | |

Overall Content Score: [LETTER]

**DETAILED FINDINGS**
For each of the 8 areas, write 150-250 words covering:
1. What's working (find something genuine to praise)
2. What's not working (be specific — quote their actual copy)
3. What competitors do differently (reference real competitor content)
4. One specific recommendation

**QUICK WINS (This Week)**
3 things they can fix immediately with specific instructions. Be concrete:
- BAD: "Improve your subject lines"
- GOOD: "Your welcome email subject is '[their actual subject].' Change it to something like '[your suggestion]' — this format gets 25-40% higher opens for DTC brands."

**BIG OPPORTUNITIES (30-90 Days)**
3 strategic content plays that would drive revenue. Each one: what to do, why it matters, estimated impact. These should be things that need professional help (things CopyDTC would do).

**WHAT A COPYDTC CONTENT SYSTEM WOULD LOOK LIKE FOR [COMPANY_NAME]**
250-350 words. Describe the specific system you'd build. What the first 30 days would look like. What results to expect. End with: "If you'd like to explore this, book a 20-minute call at [CALENDAR_LINK] and we'll walk through the full strategy."

---

Total report length: 2,500-3,500 words. Use their actual content as examples throughout. Be honest with grades. Tone: expert consultant, not salesperson.
