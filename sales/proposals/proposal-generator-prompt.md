# Proposal Generator Prompt

> **Purpose:** Claude prompt that generates a customized proposal for a specific prospect using our template structure, audit findings, and discovery call notes.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad when creating a proposal for a qualified prospect

## Contents

### The Prompt
- Input: prospect brand name, website, niche
- Input: completed audit report (or key findings)
- Input: discovery call notes (goals, budget signals, timeline, concerns)
- Input: recommended tier (Starter/Growth/Scale)
- Input: any custom deliverables or special requests

### Output
- Complete proposal following the proposal-template.md structure
- Customized scope of work with specific deliverable counts and types
- Month 1 content calendar preview
- Personalized "Why CopyDTC" section based on their specific needs
- Pricing section with recommended tier and justification
- ROI projections based on industry benchmarks and their current metrics

### Quality Bar
- Proposal should feel like it was written specifically for this prospect
- Scope of work should directly address the gaps identified in the audit
- Pricing should feel justified by the value proposition
- Total length: 5-8 pages
