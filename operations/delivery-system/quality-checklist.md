# Quality Checklist

> **Purpose:** Pre-delivery checklist that every piece of content must pass before being sent to a client. Ensures consistency, quality, and brand alignment across all deliverables.
> **Status:** Scaffold — full content to be built in subsequent prompts
> **Used by:** Brad (and future content producers) before delivering any content to a client

## Contents

### Universal Checks (Apply to Every Deliverable)
- [ ] Brand voice match — does this sound like the client's Brand Voice Bible?
- [ ] Tone appropriate for the channel (email vs social vs ads vs website)
- [ ] No spelling or grammar errors
- [ ] No placeholder text remaining ([BRAND_NAME] etc. all replaced)
- [ ] Word/character counts within spec
- [ ] At least one specific product mention (where applicable)
- [ ] CTA is clear, specific, and actionable
- [ ] No competitor names used negatively or incorrectly
- [ ] Words-to-avoid list checked — none present
- [ ] Words-to-use list checked — key terms included
- [ ] Formatting is clean and ready to paste/upload

### Email-Specific Checks
- [ ] Subject line under 50 characters (ideal) or 60 max
- [ ] Preview text is 40-90 characters and compelling
- [ ] Body copy uses short paragraphs (2-3 sentences max)
- [ ] Single clear CTA per email
- [ ] Dynamic tokens properly formatted
- [ ] Unsubscribe/compliance language noted

### Landing Page-Specific Checks
- [ ] Hero headline is 8 words or fewer
- [ ] Benefits-focused (not features-focused)
- [ ] FAQ section addresses top objections
- [ ] Image/video placement notes included
- [ ] Mobile readability considered (short paragraphs, scannable)

### Blog-Specific Checks
- [ ] Meta title is 50-60 characters with keyword
- [ ] Meta description is 150-160 characters
- [ ] Primary keyword appears 4-6 times naturally
- [ ] H2/H3 structure is logical and scannable
- [ ] Internal linking placeholders included

### Ad-Specific Checks
- [ ] Character limits respected for platform
- [ ] Hook is in the first line
- [ ] Creative direction notes included
- [ ] Multiple variations provided
- [ ] Platform-specific best practices followed

### Social-Specific Checks
- [ ] Hashtags are relevant and correctly formatted
- [ ] Captions feel native to the platform
- [ ] Visual direction is specific and actionable
- [ ] Engagement prompt included

### Final Sign-Off
- [ ] Would I be proud to show this in our portfolio?
- [ ] Does this meet the "ready to send" quality bar from the template?
- [ ] Has this been reviewed by a second set of eyes (when possible)?
