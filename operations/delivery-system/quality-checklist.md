# Quality Checklist

> **Purpose:** Pre-delivery checklist that every piece of content must pass before being sent to a client. No deliverable leaves CopyDTC without clearing every applicable check.
> **Used by:** Brad (and future content producers) before delivering any content to a client.
> **Last updated:** 2026-03-02

---

## How to Use This Checklist

### Step-by-Step Process

1. **Generate the content** using the appropriate prompt template from `client-work/templates/`.
2. **Read the output in full** before checking anything. Get a feel for whether it sounds right.
3. **Run the Universal Checks** below. Every deliverable must pass all 12.
4. **Run the Content-Type Checks** for the specific deliverable type (email, landing page, etc.).
5. **Run the Final Gate** — three questions. If any answer is "no," revise before sending.
6. **Deliver** with confidence.

### Estimated Review Time by Content Type

| Content Type | Review Time | Notes |
|---|---|---|
| Email (single) | 5-8 min | Add 3 min per email for sequences |
| Email (full sequence) | 15-25 min | Welcome, abandoned cart, post-purchase, winback |
| Landing Page | 10-15 min | Longer for advertorials — more claims to verify |
| Blog Post | 10-15 min | SEO checks add time; don't skip them |
| Ad Copy (per platform) | 8-12 min | Character counts are non-negotiable — verify every variation |
| Product Description | 5-8 min per product | Batch review is faster; still check each one individually |
| Social Media (weekly batch) | 10-15 min | Platform-specific checks differ — don't lump them together |
| SMS | 3-5 min per message | Short content, strict limits — every character matters |
| Website Copy (homepage/about) | 10-15 min | Read it as a customer would — top to bottom, no skipping |
| Case Study | 8-10 min | Verify every metric and claim against source data |
| Press Release | 5-8 min | AP style compliance is easy to miss — read twice |

## Universal Checks (Every Deliverable Must Pass All 12)

- [ ] **Brand voice match** — read 2-3 sentences aloud. Does this sound like the client's Brand Voice Bible, or does it sound generic?
- [ ] **Tone matches the channel** — email tone ≠ ad tone ≠ blog tone. Verify the register is appropriate for where this content will live.
- [ ] **Zero spelling or grammar errors** — run it through a spell check AND read it manually. Spell check misses context errors ("their" vs. "there").
- [ ] **No placeholder text remaining** — search for brackets: `[BRAND_NAME]`, `[PRODUCT]`, `[CTA_URL]`, `[DATE]`, `{{tokens}}`. Every single one must be replaced or flagged for the client.
- [ ] **Word/character counts within spec** — check against the template's output format requirements. Don't estimate — count.
- [ ] **At least one specific product mention** — where applicable. Generic content that could apply to any brand is not good enough.
- [ ] **CTA is clear, specific, and actionable** — "Shop Now" is fine. "Click Here" is not. The reader should know exactly what happens when they take the action.
- [ ] **No competitor names used negatively or incorrectly** — referencing competitors in listicles and comparison content is fine when done honestly. Trashing competitors is never acceptable.
- [ ] **Words-to-avoid list checked** — pull up the client's Brand Voice Bible. Search the deliverable for every word on their avoid list. Zero tolerance.
- [ ] **Words-to-use list checked** — confirm key brand terms, product names, and preferred phrases appear naturally. Don't force them — but they should be present.
- [ ] **Formatting is clean and ready to paste/upload** — no extra line breaks, no broken markdown, no orphaned bullet points. The client should be able to use this immediately.
- [ ] **All claims are truthful and substantiated** — no made-up statistics, no unverifiable results, no health/safety claims that the client hasn't approved. When in doubt, cut the claim.

## Content-Type Checks

### Email (7 Checks)

Applies to: welcome sequences, abandoned cart, post-purchase, promotional, winback, and any other email deliverable.

- [ ] **Subject line length** — under 50 characters ideal, 60 characters absolute max. Test how it looks truncated on mobile.
- [ ] **Preview text is 40-90 characters and compelling** — this is the second headline. It should add information, not repeat the subject line.
- [ ] **Body copy uses short paragraphs** — 2-3 sentences max per paragraph. One idea per paragraph. Wall-of-text emails don't get read.
- [ ] **Single clear CTA per email** — one action you want the reader to take. Secondary CTAs (social links, etc.) are fine in the footer but the body should drive one action.
- [ ] **Dynamic tokens properly formatted** — `{{first_name}}`, `{{product_name}}`, etc. must match the client's ESP token format exactly. Wrong tokens = broken emails sent to real customers.
- [ ] **Sequence logic is sound** — for multi-email sequences: timing makes sense, escalation is gradual, no contradictions between emails (e.g., email 2 doesn't reference something not mentioned until email 3).
- [ ] **Compliance language noted** — unsubscribe reference, physical address requirement, and any industry-specific disclosures (supplements, health claims, financial products) are flagged for the client's legal review.

---

### Landing Page (8 Checks)

Applies to: product pages, collection pages, advertorials, homepage, about page.

- [ ] **Hero headline is 8 words or fewer** — the first thing they read must be punchy. If it needs a comma, it's probably too long.
- [ ] **Benefits-focused, not features-focused** — "Sleep through the night" beats "Contains 10mg melatonin." Features can appear in supporting sections, but benefits lead.
- [ ] **Social proof is specific** — "10,000+ customers" with a real testimonial beats "Loved by many." Numbers, names, and results.
- [ ] **FAQ section addresses top objections** — not just product questions. The FAQ is where you neutralize the reasons people don't buy. Shipping, returns, ingredients, "does this actually work?"
- [ ] **Image/video placement notes are specific and actionable** — "Add lifestyle image here" is useless. "Photo: woman applying serum at bathroom mirror, morning light, no makeup, showing the 2-pump application" is useful.
- [ ] **Mobile readability confirmed** — short paragraphs, scannable subheads, no sections that would become a wall of text on a phone screen. Read it on your phone before sending.
- [ ] **Page flow follows a logical persuasion sequence** — problem → solution → proof → details → objection handling → CTA. If sections feel randomly ordered, restructure.
- [ ] **CTA appears at least twice** — once above the fold (or immediately after the hero section) and once at the bottom. Long pages may need a mid-page CTA as well.

---

### Blog / SEO (7 Checks)

Applies to: SEO blog posts, listicles, how-to posts, and any long-form content.

- [ ] **Meta title is 50-60 characters and includes the primary keyword** — check in a SERP preview tool. Truncated titles look unprofessional.
- [ ] **Meta description is 150-160 characters** — includes keyword naturally and a reason to click. This is ad copy for organic search.
- [ ] **Primary keyword appears 4-6 times naturally** — not stuffed. Read it out loud — if the keyword sounds forced in any instance, rewrite that sentence.
- [ ] **H2/H3 structure is logical and scannable** — someone skimming only the headers should understand the article's argument. No vague headers like "More Information."
- [ ] **Internal linking opportunities noted** — flag 2-3 places where the client could link to their product pages, collection pages, or other blog posts. Include suggested anchor text.
- [ ] **Introduction hooks the reader in 2-3 sentences** — no throat-clearing. No "In today's world..." or "Have you ever wondered..." Get to the point.
- [ ] **Product mentions feel editorial, not advertorial** — the product should solve a problem raised in the content. If the product mention feels like a forced ad break, rewrite the transition.

---

### Ad Copy (6 Checks)

Applies to: Meta (Facebook/Instagram), Google (Search/PMax), TikTok, and any other paid media creative.

- [ ] **Character limits respected for the specific platform** — Facebook primary text, Google headline/description limits, TikTok caption limits. Every variation, every field. No exceptions.
- [ ] **Hook stops the scroll** — the first line (Facebook/Instagram) or first 3 seconds (TikTok/video) must create enough curiosity, emotion, or pattern interruption that someone pauses. Test: would YOU stop scrolling?
- [ ] **Creative direction is specific and actionable** — not "use a lifestyle image." Specify the scene, the mood, the framing, the text overlay placement. A designer or video editor should be able to execute without asking questions.
- [ ] **CTA matches the campaign objective** — awareness ads don't need "Buy Now." Retargeting ads shouldn't say "Learn More." Match the CTA to where the audience is in the funnel.
- [ ] **No prohibited claims** — no income claims, no "guaranteed" results, no before/after that implies medical outcomes, no superlatives that can't be substantiated ("the best," "the only," "#1"). Platform ad policies are strict — one violation can get the account banned.
- [ ] **Multiple variations provided** — minimum 3-5 variations per platform per concept. Clients need options to test. One ad is not a deliverable — a testing framework is.

---

### Product Descriptions (6 Checks)

Applies to: individual product descriptions, catalog updates, new product launches.

- [ ] **Short description is 50-75 words** — this is the card/grid version. One compelling paragraph that makes someone click through. Count the words.
- [ ] **Long description is 150-300 words** — this is the full product page version. Enough to sell without overwhelming. Count the words.
- [ ] **Bullet points start with benefits, not features** — "Wake up without the 3pm crash" before "Contains 200mg L-theanine." Every bullet leads with what the customer gets.
- [ ] **Sensory or emotional language is present** — the customer can't touch, smell, or taste through a screen. Your words have to do that work. At least 2-3 sensory details per product.
- [ ] **At least one objection is addressed** — price justification, ingredient sourcing, "does this actually work," shipping/returns. Weave it into the description naturally.
- [ ] **Meta description is included** — 150-160 characters, keyword-rich, written to earn the click from a search result. This is not optional — every product page needs one.

---

### Social Media (6 Checks)

Applies to: Instagram posts, TikTok scripts, Twitter/X content, and any organic social deliverable.

- [ ] **Instagram hook lands before the truncation point** — captions cut off at ~125 characters in-feed. The hook and the reason to tap "more" must land before that cutoff.
- [ ] **TikTok hook is in the first 1-3 seconds** — "Wait, your skincare routine is doing WHAT?" beats "Hey guys, today I want to talk about..." The hook determines whether anyone sees the rest.
- [ ] **Twitter/X posts are under 280 characters** — and ideally under 200 for maximum engagement. Threads are fine for longer content but each tweet must stand on its own.
- [ ] **Hashtags follow platform best practices** — Instagram: 5-15 relevant hashtags mixed between broad and niche. TikTok: 3-5 trending + niche. Twitter: 1-2 max or none.
- [ ] **Visual direction is specific** — for every post that needs an image or video, provide specific direction: subject, composition, mood, colors, text overlay content and placement.
- [ ] **Content matches platform culture** — Instagram is aspirational and visual. TikTok is raw, fast, and trend-driven. Twitter is conversational and opinionated. Content that works on one platform often fails on another. Don't cross-post — cross-adapt.

---

### SMS (5 Checks)

Applies to: welcome messages, promotional texts, abandoned cart SMS, winback SMS, and any text message deliverable.

- [ ] **Under 160 characters** — this is a hard limit. Every character over 160 turns one text into two, doubling the cost and breaking the reading experience. Count every character including spaces.
- [ ] **One emoji maximum** — SMS isn't Instagram. One well-placed emoji adds personality. Two or more looks like spam. Zero is also fine.
- [ ] **CTA is unmistakable** — the reader should know exactly what to do in under 3 seconds of reading. "Shop now: [link]" or "Reply YES to claim" — not a paragraph ending with a vague suggestion.
- [ ] **Opt-out included or compliance noted** — "Reply STOP to unsubscribe" or a note to the client that their SMS platform handles this automatically. Never send without opt-out compliance.
- [ ] **Reads like a text, not a marketing blast** — read it as if a friend sent it. Would you feel talked to, or marketed at? SMS lives in the most personal channel on someone's phone. Respect that.

---

### Website Copy (6 Checks)

Applies to: homepage, about page, and other site-wide copy not covered by landing page or product description checks.

- [ ] **Hero section works in isolation** — if someone saw only the hero headline + subheadline + CTA button, would they understand what the brand sells and why they should care?
- [ ] **Brand story is specific, not generic** — "We started because we saw a gap in the market" is garbage. The founder story should have a real moment, a real frustration, a real decision.
- [ ] **Navigation flow is logical** — copy sections should guide the reader down the page in a natural sequence. If you rearranged the sections, would anyone notice? If yes, the flow is working.
- [ ] **Social proof is woven throughout** — not dumped in one section. Testimonials, trust badges, press mentions, and customer counts should appear where they reinforce the surrounding copy.
- [ ] **SEO fundamentals covered** — H1 includes primary keyword, meta title and description provided, image alt text suggestions included.
- [ ] **Every section has a purpose** — if you can't articulate why a section exists and what it's supposed to make the reader feel or do, cut it.

---

### Case Study / Press Release (5 Checks)

Applies to: client case studies and press releases.

- [ ] **Every metric and claim is sourced and verified** — "Revenue increased 47%" requires a source. If the client provided the number, note that. If you calculated it, show the math. No unverifiable claims.
- [ ] **Narrative arc is complete** — case studies: challenge → solution → results → takeaway. Press releases: what happened → why it matters → quote → details → boilerplate. No dead ends.
- [ ] **Quotes sound like a real person said them** — not corporate speak. Read founder/customer quotes aloud. If they sound like a press release instead of a person, rewrite them.
- [ ] **Format matches industry standard** — press releases follow AP style, under 500 words, include all required sections (dateline, boilerplate, contact info). Case studies include a metrics snapshot at the top.
- [ ] **CTA is appropriate** — case studies should drive toward a consultation or next step. Press releases should include contact information and a clear "for more information" path.

## Final Gate

Every deliverable must pass all three questions before delivery. If any answer is "no," revise.

| # | Question | What a "Yes" Looks Like |
|---|---|---|
| 1 | **Would I put this in our portfolio?** | You'd show this to a prospect as proof of what CopyDTC produces. It demonstrates clear strategic thinking, strong brand voice execution, and professional-grade writing. Not just "good enough" — genuinely good. |
| 2 | **Is this worth $3K-10K/month?** | The client is paying agency rates. This content should feel like it came from a team of specialists, not a template with the blanks filled in. If a client compared this to what they could get from a $500/month freelancer, the quality gap should be obvious. |
| 3 | **Does this sell, or does it just exist?** | Every piece of content should move the reader toward a specific action — buying, subscribing, clicking, engaging. If the content is informative but passive, it's not done. Good DTC copy always has a commercial purpose, even when it's subtle. |
