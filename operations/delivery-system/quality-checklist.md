# CopyDTC Quality Checklist

Run every deliverable through this before sending to a client.

---

## Universal Checks (Every Deliverable)

### Voice & Brand
- [ ] Read it out loud. Does it sound like this client's brand?
- [ ] Check Brand Voice Bible "always use" words — are they present?
- [ ] Check Brand Voice Bible "never use" words — Ctrl+F each one
- [ ] Is the tone right for this channel? (Email tone differs from ad tone differs from blog tone)

### Copy Quality
- [ ] Is the headline/hook the strongest version? Write 2 alternatives and compare.
- [ ] Are paragraphs 3 sentences or fewer?
- [ ] Delete any sentence. Does the piece get worse? If not, cut it.
- [ ] Benefits lead over features?
- [ ] Clear CTA? Reader knows exactly what to do next?
- [ ] First line strong enough to earn the second line?
- [ ] Last paragraph drives action (not just trails off)?

### Accuracy
- [ ] Zero spelling errors (spell check AND manual read)
- [ ] Zero grammar errors
- [ ] Product names spelled and capitalized correctly
- [ ] All prices, percentages, numbers accurate
- [ ] All claims truthful and substantiated
- [ ] Regulated category? (supplements, skincare, health) — flag for client legal review

### Formatting
- [ ] Clean, consistent spacing
- [ ] Headers used correctly
- [ ] CTA buttons/links clearly marked with exact text
- [ ] Image directions clear enough for a designer
- [ ] Correct length per the brief

---

## Email Checks (Add These for Any Email)
- [ ] Subject line under 50 characters
- [ ] Preview text written, under 90 characters
- [ ] Subject and preview text don't repeat each other
- [ ] Scannable on mobile (short paragraphs, clear CTA)
- [ ] Dynamic tokens correct: [FIRST_NAME], [PRODUCT_NAME], etc.
- [ ] Exactly ONE primary CTA (multiple CTAs kill clicks)
- [ ] Sequence flow: connects to previous email, sets up next one

## Landing Page Checks
- [ ] Hero headline under 10 words, communicates core value
- [ ] Answers "what, who, why" above the fold
- [ ] Social proof present (testimonials, reviews, trust badges)
- [ ] Objections addressed before final CTA
- [ ] Mobile layout considered (CTA visible without scrolling?)
- [ ] FAQ answers real questions, not marketing fluff

## Blog/SEO Checks
- [ ] Primary keyword in: title, H1, first 100 words, 1-2 H2s, meta description
- [ ] Keyword density 0.5-1.5% (not stuffed)
- [ ] Meta title 50-60 characters, keyword near front
- [ ] Meta description 150-160 characters with CTA
- [ ] Internal link placeholders included
- [ ] Content is genuinely useful (would rank on quality alone?)

## Ad Copy Checks
- [ ] Headlines within platform character limits (Meta: 40, Google: 30)
- [ ] Descriptions within limits (Google: 90)
- [ ] Hook would actually stop a scroll (be honest)
- [ ] Creative direction specific enough for designer/editor
- [ ] CTA matches campaign objective
- [ ] No prohibited claims for the ad platform
- [ ] Multiple variations provided (min 3 hooks)

## Product Description Checks
- [ ] Short description 50-75 words
- [ ] Long description 150-300 words
- [ ] Bullets start with benefits, not features
- [ ] Sensory language used
- [ ] Primary objection addressed
- [ ] SEO meta description written

## Social Media Checks
- [ ] Instagram: strong hook before "...more" truncation (first 125 chars)
- [ ] TikTok: hook in first 1-3 seconds
- [ ] Twitter: under 280 characters
- [ ] Hashtags appropriate per platform
- [ ] Visual direction clear and specific

## SMS Checks
- [ ] Under 160 characters total
- [ ] One emoji max
- [ ] Clear CTA with link placeholder
- [ ] "Reply STOP to unsubscribe" included

---

## Final Gate

Before sending ANY deliverable:

- [ ] **Would I put this in my portfolio?** If no, it's not ready.
- [ ] **If I paid $3K-$10K/month for this, would I be happy?** If no, revise.
- [ ] **Does this piece SELL or just EXIST?** Every piece should drive a business outcome.

---

## How to Use

1. Writer completes the deliverable
2. Run Universal Checks + relevant Channel Checks
3. Fix any failures
4. If contractor work: Brad reviews against same checklist
5. Only after passing does it go to client
6. Log recurring issues in client's Brand Voice Bible

Time per review: 3-5 min for ads/SMS, 5-10 min for emails/social, 10-15 min for landing pages/blogs.
